Installs BepInEx when it is missing and moves it to a newer pack during a scheduled restart. Every server on this install shares one BepInEx, so this covers all of them.
Also check Hexium
Hexium is a second mod site. Whoever runs it is not named on the site, and its accounts are Discord sign-ins, so BakaLoader cannot tell you that an author there is the same person as the author of the same name on Thunderstore. With this on, your machine contacts hexium.gg about four times an hour while BakaLoader is open, and that site says it keeps request logs for up to ninety days. Nothing is installed from Hexium unless you ask for it and accept what it is.
